# Septima Congruence Auditor
**SC Auditor · Date–Weekday Checker** — a browser-based, offline-capable weekday calculator and document/spreadsheet date–weekday auditor built around Septima Congruence (SC-400).

The application supports local document and spreadsheet checks, PDF review/annotation, and downloadable audit evidence. The files are processed in the browser.

## Terminology

- **Septima Congruence Auditor** — official website and installed-app name.
- **SC Auditor** — short app name for compact displays.
- **Date–Weekday Checker** — descriptive subtitle, not a separate application name.
- **Septima Congruence** — name of the mathematical method.
- **SC-400** — designation used in the mathematical and computational implementation.

Existing signed audit-proof formats are preserved for backward compatibility.
