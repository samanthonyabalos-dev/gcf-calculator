# Septima Congruence and Septima Auditor

Public mathematical name: **Septima Congruence (SC)**. The 400-year cached implementation is **SC-400** and the browser application is **Septima Auditor — Date–Weekday Checker**.

This name change does not assert new mathematical provenance or ownership. The original source comments preserve attribution to Albadora. Historic internal source names and APIs (such as `gcf-engine.js`, `GCFEngine`, `gcf`, `gcf400`, `gcf400-audit-evidence-v1`) remain for backwards compatibility with stored audit signatures and previous users. New API aliases `SeptimaEngine`, `SCEngine`, `sc`, `sc400` are available. These internal legacy identifiers are not part of the public product name.

The revised service worker installs a new cache, with cleanup of earlier cache names. Original test logs and screenshot captures retain their historical labels; they have not been altered. The source may require external PDF.js and OCR libraries; rebranding is not new evidence of full PRC annotation compatibility.
